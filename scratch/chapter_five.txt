CHAPTER FIVE
CONCLUSION AND RECOMMENDATIONS

5.1 Conclusion
This project successfully designed and implemented a secure end-to-end encrypted instant messaging system using hybrid cryptography. The system was developed to provide confidential and integrity-protected communication between two users without exposing plaintext messages to the server.

The implementation achieved the intended security objectives by combining symmetric encryption, asymmetric encryption, and hashing into a single communication workflow. AES-256-CBC was used to protect the message content, RSA-2048 was used to secure the exchange of the symmetric key, and SHA-256 was used to verify that messages were not altered during transmission.

One of the main strengths of the system is that cryptographic processing takes place on the client side. This means that sensitive message content and private key material remain under the control of the communicating users rather than the server. As a result, the server functions only as a relay component and does not have access to plaintext data.

The study also demonstrated that hybrid cryptography is suitable for instant messaging because it balances security and efficiency. Symmetric encryption handles the actual message data quickly, while asymmetric encryption is reserved for key exchange, where its slower performance is acceptable. Hashing adds an additional layer of protection by allowing the receiver to detect tampering.

In summary, the project met its objectives and produced a functional prototype that shows how secure instant messaging can be implemented using modern cryptographic techniques.

5.2 Recommendations
Although the system was successful within its design scope, there are several areas where it can be improved in future work. The following recommendations are made:

1. Implement Forward Secrecy
Future versions of the system should include forward secrecy so that the compromise of one key does not expose previously exchanged messages.

2. Add Stronger Public Key Verification
To reduce the risk of impersonation or man-in-the-middle attacks, the system should include improved public key verification methods such as fingerprint comparison or certificate-based validation.

3. Support Group Messaging
The current system is limited to one-to-one communication. Extending it to support secure group chats would improve its practical usefulness.

4. Improve Metadata Protection
Future versions should explore ways to reduce metadata exposure, including sender identity masking, timestamp obfuscation, or privacy-preserving routing techniques.

5. Introduce Message Archival Options
Since the present design discards session data after use, an optional secure archival mechanism could be added for users who need message history while still preserving privacy.

6. Expand to Mobile Platforms
The system should be adapted for mobile devices so that secure messaging can be accessed across a wider range of environments.

7. Conduct Broader Security Testing
Additional testing should be performed to evaluate resilience against public key spoofing, browser compromise, replay attempts, and other real-world attack scenarios.

8. Optimize Performance for Larger Payloads
Although the system is intended for text messaging, future work could examine performance improvements for larger messages or richer content types.

5.3 Contributions of the Study
This study makes several contributions to the field of secure communication.

1. It presents a practical model for combining AES, RSA, and SHA-256 in a single secure messaging workflow.
2. It demonstrates how end-to-end encryption can be implemented on the client side to protect user privacy.
3. It provides an educational prototype that clearly illustrates how secure messaging systems operate.
4. It highlights the importance of secure key management and integrity verification in real-time communication.

5.4 Final Remarks
Secure instant messaging continues to be an important area of research because of the increasing need for privacy, authenticity, and data integrity in digital communication. This project shows that a well-designed hybrid cryptographic system can provide a strong foundation for protecting message content while remaining usable in practice.

The work also reinforces the idea that security should not depend only on encryption strength, but also on correct system design, proper key handling, and consistent integrity checking. With further development, the prototype can serve as a basis for more advanced secure communication systems.

Overall, the project demonstrates that hybrid cryptography remains an effective and practical approach for building secure end-to-end encrypted instant messaging applications.
